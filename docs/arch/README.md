# DSN 설계 문서

설계 기준일: 2026-09-08.

DSN은 다양한 Source의 메시지를 낮은 부하로 수집하고, Workspace가 해석한 record를 저장하여 View로 제공하는 플랫폼이다. 특정 테스트 시나리오나 payload 형식에 종속되지 않는다.

## 설계 상태

- **확정**: 현재 설계의 필수 동작과 제약.
- **제안**: 검토 중인 구현 구조 또는 API 초안.
- **미정**: 구체 규격이나 운영 값이 정해지지 않은 항목.

공개 인터페이스의 역할과 책임을 정의한다. 메서드 시그니처, 전송 규약 및 미정 항목은 [결정 사항과 미정 사항](05-decisions.md)에 정리한다.
