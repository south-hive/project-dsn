<a id="x-01"></a>
## X-01. RPC 인터페이스 → Mock 인수 검증

**상태:** 미착수

**단계:** 1차 개발

**선행 조건:** F-03, I-04

**하위 작업**

- [ ] `X-01.1` 계약 검증용 RPC client로 정상·바이너리·잘못된 요청 실행
- [ ] `X-01.2` Mock 종료·출력 지연·RPC session 재생성 실행
- [ ] `X-01.3` Source 담당자에게 전달할 재현 명령과 RPC 결과 기록

**산출물:** RPC/Mock 인수 보고, 계약 검증 예시

**완료 기준:** 실제 RPC 경계와 Mock 입력 호환성을 검증한다. 검증 client를 production Source SDK나 kernel 구현으로 취급하지 않는다.

**인계 증거:** 변경 위치·build/검증 명령·환경·실제 결과·남은 제약을 완료 기록에 첨부한다.

**담당자 결정:** 확정된 RPC·모듈 계약 안의 구현 및 문서·검증 구성

**협의 조건:** RPC 입력/응답 의미·Source 식별·소유권·DSN 배포 또는 공개 계약을 새로 정하거나 변경할 때

**협의 대상·관련 경계:** I·H·해당 DSN 계약 소비자; RPC 외부 호환성은 Source 담당자 — DC-02, DC-10 ([결정 범위](../14-decision-boundaries.md)). 기존 계약 준수 시 재협의 없이 진행한다.

## X-04. QA 평가·모니터링·조치 후속 계획

**상태:** 보류 — 1차 완료 이후

**단계:** 1차 완료 이후

**선행 조건:** X-05, F-06, E-02

**하위 작업**

- [ ] `X-04.1` 1차 인수 결과와 위험 등록부를 기준으로 목표·평가 방법 구체화
- [ ] `X-04.2` 선택된 monitoring 구현과 비교 평가 수행
- [ ] `X-04.3` 실제 근거로 조치 필요성을 검토하고 필요한 후속 작업 정의

**산출물:** 1차 이후 QA 평가 결과, 관측·조치 검토 기록

**완료 기준:** 1차 완료의 선행 조건이 아니다. 평가 환경과 근거를 기록하며 위험이 확인되지 않은 범위를 안전 보장으로 확대하지 않는다.

**인계 증거:** 변경 위치·build/검증 명령·환경·실제 결과·남은 제약을 완료 기록에 첨부한다.

**담당자 결정:** 1차 이후 평가 초안과 원시 결과 정리

**협의 조건:** QA 목표·관측 구현·개선 조치로 타 모듈 계약/비용을 바꿀 때

**협의 대상·관련 경계:** E와 해당 QA 영향 모듈; 기준 변경 시 관련 계약 담당 — DC-11 ([결정 범위](../14-decision-boundaries.md)). 기존 계약 준수 시 재협의 없이 진행한다.
