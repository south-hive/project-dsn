<a id="x-01"></a>
## X-01. C++ → Mock 인수 검증

**상태:** 미착수

**선행 조건:** S-04, I-04

**하위 작업**

- [ ] `X-01.1` 패키지 기반 정상·바이너리·손상 입력 실행
- [ ] `X-01.2` Mock 종료·출력 지연·재attach 실행
- [ ] `X-01.3` 재현 명령과 결과 기록

**산출물:** Mock 인수 보고

**완료 기준:** 실제 wire 호환성과 발행 비대기를 확인한다. console 속도를 DSN 처리량으로 보고하지 않는다.

**인계 증거:** 변경 위치·build/검증 명령·환경·실제 결과·남은 제약을 완료 기록에 첨부한다.

<a id="x-02"></a>
## X-02. C++ → DSN → Record 통합

**상태:** 미착수

**선행 조건:** X-01, I-03, R-06, P-02, H-02

**하위 작업**

- [ ] `X-02.1` 실제 입력부터 두 Workspace와 저장 연결
- [ ] `X-02.2` FIFO·파싱 실패·포화·저장 실패 실행
- [ ] `X-02.3` ref count·record·오류 집계 대조

**산출물:** 최소 전체 경로 통합 보고

**완료 기준:** 공유 원본과 record 기대 결과가 일치하고 실패 경로에 소유 참조가 남지 않는다.

**인계 증거:** 변경 위치·build/검증 명령·환경·실제 결과·남은 제약을 완료 기록에 첨부한다.

## X-03. 전체 배포와 lifecycle 장애 통합

**상태:** 미착수

**선행 조건:** H-03, K-04, X-02, E-03, A-02

**인계 증거:** 변경 위치·build/검증 명령·환경·실제 결과·남은 제약을 완료 기록에 첨부한다.

## X-05. Release 산출물과 문서 인수

**상태:** 미착수

**선행 조건:** X-04, P-03, S-04, K-04, H-03

**하위 작업**

- [ ] `X-05.1` 이미지·SDK·Mock·plugin·예제 버전과 checksum 정리
- [ ] `X-05.2` 새 환경에서 배포·재현 절차 확인
