<a id="k-01"></a>
## K-01. Kernel·eBPF 발행 경로 구체화

**상태:** 미착수

**선행 조건:** F-01, F-03

**하위 작업**

- [ ] `K-01.1` 호출 문맥별 메모리·버퍼·동기화 제약 확인
- [ ] `K-01.2` driver/eBPF 추출 및 사용자 공간 중계 책임 정의
- [ ] `K-01.3` detach/unload·중계 중단의 자원 수명 정의

**산출물:** adapter 설계, 중계 경계, 커널 검증 계획

**완료 기준:** 각 실행 경로와 teardown 규칙을 지원 커널 및 검증 장비에 연결하고 C++ API와 구분한다.

**인계 증거:** 변경 위치·build/검증 명령·환경·실제 결과·남은 제약을 완료 기록에 첨부한다.

<a id="k-02"></a>
## K-02. Kernel Driver Source 구현

**상태:** 미착수

**선행 조건:** K-01, F-02

**하위 작업**

- [ ] `K-02.1` driver 발행 및 적재·폐기 구현
- [ ] `K-02.2` 중계·전송 계약 연결
- [ ] `K-02.3` attach/detach·module 종료 검증

**산출물:** driver 통합 코드, build·실행 예제

**완료 기준:** 목표 커널에서 발행·포화·중계 부재·종료를 확인하고 원 프로젝트 대기나 수명 위반이 없다.

**인계 증거:** 변경 위치·build/검증 명령·환경·실제 결과·남은 제약을 완료 기록에 첨부한다.

<a id="k-03"></a>
## K-03. eBPF Source 및 중계 구현

**상태:** 미착수

**선행 조건:** K-01, F-02

**하위 작업**

- [ ] `K-03.1` eBPF 발행과 이벤트 전달 구조 구현
- [ ] `K-03.2` 필요한 사용자 공간 소비·전송 중계 구현
- [ ] `K-03.3` 발행 해제·중계 종료·재attach 검증

**산출물:** eBPF 예제, 중계, 환경별 검증 기록

**완료 기준:** 목표 환경에서 로딩·발행·detach를 통과하며 공통 DSN 규약으로 전달한다. 손실 지점과 관측 범위를 명시한다.

**인계 증거:** 변경 위치·build/검증 명령·환경·실제 결과·남은 제약을 완료 기록에 첨부한다.

<a id="k-04"></a>
## K-04. Kernel·eBPF → Mock 통합

**상태:** 미착수

**선행 조건:** K-02, K-03, I-04

**하위 작업**

- [ ] `K-04.1` 각 발행 경로를 Mock에 연결
- [ ] `K-04.2` 수신기 중단·재시작·포화 확인
- [ ] `K-04.3` 환경 및 kernel/중계 자원 해제 결과 기록

**산출물:** 경로별 통합 결과, 실행 절차

**완료 기준:** 각 경로의 입력을 확인하고 검증하지 못한 환경을 성공으로 표기하지 않는다.

**인계 증거:** 변경 위치·build/검증 명령·환경·실제 결과·남은 제약을 완료 기록에 첨부한다.
