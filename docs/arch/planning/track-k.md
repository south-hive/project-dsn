# 외부 연동: Kernel·eBPF Source

Source 내부 구현은 해당 Source 담당자가 결정한다. 이 문서는 DSN 구현 task 목록이 아니며 아래 ID는 기존 참조를 위한 외부 범위 표식이다.

DSN이 제공하는 것은 [RPC 연동 계약·Mock](../03-source-and-mock.md)이다. 탄창, sender, 언어별 API/ABI, kernel/eBPF 발행, 중계 및 unload 구현은 이 프로젝트의 개발·인수 선행 조건으로 관리하지 않는다.

<a id="k-01"></a>
## K-01 — 외부 Source 담당 범위

내부 작업 분해와 완료 판단은 Source 담당자가 정한다. DSN과 협의할 대상은 RPC 요청·호환성·endpoint·Source 식별 및 실패 의미다.
