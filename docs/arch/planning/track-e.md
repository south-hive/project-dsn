<a id="e-01"></a>
## E-01. Error Intake와 동일 오류 집계

**상태:** 미착수

**선행 조건:** F-04

**하위 작업**

- [ ] `E-01.1` 오류 본문·시각 분리 및 접수 구현
- [ ] `E-01.2` 본문 동일성·first/last/count 갱신 구현
- [ ] `E-01.3` Admin 부재·집계 포화·재귀 오류 경로 검증

**산출물:** Diagnostics core, 집계 테스트

**완료 기준:** 같은 본문을 집계하고 다른 내용은 구분한다. Admin을 기다리지 않으며 집계 한도와 fallback을 명시한다.

**인계 증거:** 변경 위치·build/검증 명령·환경·실제 결과·남은 제약을 완료 기록에 첨부한다.

<a id="e-02"></a>
## E-02. Source 수신량과 폐기 계측

**상태:** 미착수

**선행 조건:** E-01, I-03, F-06

**하위 작업**

- [ ] `E-02.1` source_id별 수신량·폐기 지점 계측
- [ ] `E-02.2` 시간 구간 snapshot과 비용 측정
- [ ] `E-02.3` 추후 경고·폐기 지점과 미정 임계값 구분

**산출물:** 수신 지표, snapshot 검증, overhead 결과

**완료 기준:** 수신량을 실제 발행량으로 오표기하지 않고 구간·Source 구분을 검증한다. 임계값을 확정 정책으로 임의 도입하지 않는다.

**인계 증거:** 변경 위치·build/검증 명령·환경·실제 결과·남은 제약을 완료 기록에 첨부한다.

<a id="e-03"></a>
## E-03. 해당 Source 연결 종료 구현

**상태:** 미착수

**선행 조건:** E-01, I-01, F-02

**하위 작업**

- [ ] `E-03.1` 오류 분류와 session 제어 연결
- [ ] `E-03.2` 해당 Source 종료·다른 Source 유지 검증
- [ ] `E-03.3` 신규 attach 허용·재발 반복 검증

**산출물:** 연결 제어, 다중 Source 장애 테스트

**완료 기준:** 주입한 심각 오류의 대상만 종료하며 기본 영구 차단을 두지 않는다. 중계 Source 매핑을 검증한다.

**인계 증거:** 변경 위치·build/검증 명령·환경·실제 결과·남은 제약을 완료 기록에 첨부한다.
