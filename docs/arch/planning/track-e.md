## E-01. Error Intake와 동일 오류 집계

**상태:** 미착수

**단계:** 1차 개발

**선행 조건:** F-04

**하위 작업**

- [ ] `E-01.1` 오류 본문·시각 분리 및 접수 구현
- [ ] `E-01.2` 본문 동일성·first/last/count 갱신 구현
- [ ] `E-01.3` Admin 부재·집계 포화·재귀 오류 경로 검증

**산출물:** Diagnostics core, 집계 테스트

**완료 기준:** 같은 본문을 집계하고 다른 내용은 구분한다. Admin을 기다리지 않으며 집계 한도와 fallback을 명시한다.

**인계 증거:** 변경 위치·build/검증 명령·환경·실제 결과·남은 제약을 완료 기록에 첨부한다.

**개발 계약 보완:** GAP-05·09: 집계 초기 한도·초과 동작·source_id 미확인 오류 및 first/last/count의 기본 갱신 의미를 명시한다. [점검 목록](../12-engineering-readiness.md)

**담당자 결정:** 규정된 동일성을 지키는 집계 자료구조와 테스트

**협의 조건:** ErrorEvent 필드·동일성·갱신 의미·공개 집계 한도/fallback을 바꿀 때

**협의 대상·관련 경계:** 오류 발생 모듈 I/R/H와 A; record 영향 P — DC-08, DC-09 ([결정 범위](../14-decision-boundaries.md)). 기존 계약 준수 시 재협의 없이 진행한다.

<a id="e-02"></a>
## E-02. Source 수신량·폐기 모니터링 후속 구체화

**상태:** 보류 — 1차 완료 이후

**단계:** 1차 완료 이후

**선행 조건:** E-01, I-03, F-06, X-05

**하위 작업**

- [ ] `E-02.1` 1차 산출물과 QA 위험을 기준으로 수신량·폐기 관측 범위 선택
- [ ] `E-02.2` 수집 방법·지표 계약·비용 검증 방법을 후속 설계
- [ ] `E-02.3` 선택된 계측 구현·검증 및 결과 기록

**산출물:** 1차 이후 관측 설계와 계측 결과

**완료 기준:** 1차 인수 이후에 수행한다. 수신과 발행의 차이 및 관측 비용을 구분하고 구체 도구·임계값은 후속 설계에서 정한다.

**인계 증거:** 변경 위치·build/검증 명령·환경·실제 결과·남은 제약을 완료 기록에 첨부한다.

**담당자 결정:** 1차 이후 관측 후보의 실현 방법과 시험 초안

**협의 조건:** 지표 의미·수집 위치·호출 경로 비용·공개 운영 설정을 정할 때

**협의 대상·관련 경계:** 관측 대상 외부 Source 담당/I/R/P/V/H와 X 중 영향받는 담당 — DC-11 ([결정 범위](../14-decision-boundaries.md)). 기존 계약 준수 시 재협의 없이 진행한다.

<a id="e-03"></a>
## E-03. 해당 Source 연결 종료 구현

**상태:** 미착수

**단계:** 1차 개발

**선행 조건:** E-01, I-01, F-02

**하위 작업**

- [ ] `E-03.1` 오류 분류와 session 제어 연결
- [ ] `E-03.2` 해당 Source 종료·다른 Source 유지 검증
- [ ] `E-03.3` 신규 attach 허용·재발 반복 검증

**산출물:** 연결 제어, 다중 Source 장애 테스트

**완료 기준:** 주입한 심각 오류의 대상만 종료하며 기본 영구 차단을 두지 않는다. 중계 Source 매핑을 검증한다.

**인계 증거:** 변경 위치·build/검증 명령·환경·실제 결과·남은 제약을 완료 기록에 첨부한다.

**담당자 결정:** 확정 판정 입력을 연결 제어로 전달하는 구현

**협의 조건:** 논리 Source/물리 session 종료 의미 또는 다른 Source 영향을 바꿀 때

**협의 대상·관련 경계:** I·K; Source 재접속 계약 S — DC-02, DC-08 ([결정 범위](../14-decision-boundaries.md)). 기존 계약 준수 시 재협의 없이 진행한다.
